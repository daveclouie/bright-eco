BRIGHT ECO SOLAR - PHASE 1 (about 30%): login, roles, users, inventory, basic billing

SETUP (XAMPP)
1. Copy the "bright-eco" folder into C:\xampp\htdocs\
2. Start Apache and MySQL in XAMPP.
3. Open http://localhost/phpmyadmin, go to Import, choose database/schema.sql, click Import.
4. If your MySQL has a password, edit config/db.php.
5. Open http://localhost/bright-eco/ and log in: admin / admin123
6. Change the admin password, then add Owner and Staff accounts in Users.

ONGOING!!! (remaining 70%): reports, cost estimation, void bill, password change/reset,
login attempt limit, backups, supplier records.
